# Softline Valuation: DCF & Comparable Companies

Финансово-аналитический проект по оценке стоимости ПАО «Софтлайн» двумя подходами: методом дисконтированных денежных потоков (DCF) и методом рыночных мультипликаторов.

## Цель проекта

Построить комплексную модель оценки стоимости компании, сравнить результаты DCF и comparable companies valuation и сформировать итоговый диапазон справедливой стоимости акции.

## Что реализовано

- анализ исторической финансовой отчётности;
- прогноз операционных показателей на 2026–2030 гг.;
- расчёт Free Cash Flow to Firm (FCFF);
- расчёт стоимости капитала по CAPM;
- оценка стоимости долга и WACC;
- расчёт Terminal Value по модели Gordon Growth;
- дисконтирование прогнозных денежных потоков и Terminal Value;
- расчёт Enterprise Value и Equity Value;
- сравнительная оценка по EV/Revenue, EV/EBITDA, EV/EBIT и P/E;
- сопоставление DCF-оценки с рыночной ценой;
- формирование итогового диапазона стоимости акции.

## Основные результаты модели

- DCF Enterprise Value: около 35.95 млрд RUB
- DCF Equity Value: около 21.14 млрд RUB
- DCF implied price per share: 52.86 RUB
- EV/EBITDA comparable implied price per share: 103.42 RUB
- Рыночная цена, использованная в модели: 79 RUB
- Итоговый диапазон оценки: 52.86–103.42 RUB за акцию

## Структура Excel-модели

### Data
Исходные финансовые данные компании.

### Historical analysis
Анализ исторических финансовых и операционных показателей.

### Free Cash Flow to Firm
Прогноз выручки, EBIT, NOPAT, D&A, CAPEX, NWC и FCFF на 2026–2030 гг.

### WACC
Расчёт стоимости собственного капитала по CAPM, стоимости долга и итогового WACC.

### TV (Terminal Value)
Расчёт терминальной стоимости по модели Gordon Growth.

### Discounting
Дисконтирование прогнозных FCFF и Terminal Value, расчёт Enterprise Value и Equity Value.

### Multiples Valuation
Сравнительная оценка Softline относительно публичных IT-компаний по EV/Revenue, EV/EBITDA, EV/EBIT и P/E.

### Valuation Summary
Сопоставление результатов двух методов и итоговый диапазон стоимости акции.
